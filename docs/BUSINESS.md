# 事業方針（正典）

最終更新: 2026-09-13 / 版: v0.5.1（2.5 と 7 に日本語ダイジェストと投稿源の復帰を追記）（本命を海外ソフトウェアベンダーに置き直した。朝の v0.1〜v0.4 は `docs/decided-not-to-do.md` に経緯）

この文書は「なぜやるのか、どこに立つか、何を拾い何を拾わないか、何を測るか」の正典。
日々の状態や次の一手は `docs/HANDOFF.md`。捨てた案は `docs/decided-not-to-do.md`。ここには方針だけを書く。方針を変えたらここを直す。

## 0. 一行で

「なぜ日本人は優れた IT サービスを買わないのか」を、装置で再現性のある形にして、海外のソフトウェアベンダーに高く売る。日本語のサイト・動画・SNS は、その公開実験場。

## 1. なぜやるのか

- タカさんが証明したいこと: 一人でも、人が知りえない情報を得て、道具で活用すれば、まったく別の場所に立てる。趣味や人脈の有無を言い訳にしない。
- 他人の台（TikTok の再生、アフィリエイトの成果）で張る限り、胴元には勝てない。持っている装置を、自分が支払いを握る形に組み替える。
- 「日本人はなぜ買わないか」は、アメリカ人には理解できず、それを英語で説明できる日本人はほとんどいない。タカさんは日本で IT を教える人間で、IBM と Apple にいて、本がある。海外の人が信用できる履歴を持つ数少ない一人。
- 売り手は世の中に死ぬほどいて、売れる人はごく一部。だから売れる方法を持つ人は売り手にとって神様になる。ただし「送客」では誤差でしかない。売るのは送客ではなく、**再現性のある方法とその証拠**。
- 続いている前提（project-haru の codex）: 遊び→整理→既存の場で試す→波紋。仕掛け志向。完全自走。いいねで測らない。のんびり＝自律。なんちゃって翻訳者。

## 2. どこに立つか

### 2.1 顧客と商品

- 顧客: 日本に入りたい、または日本からの流入を説明できない、海外のソフトウェアベンダー（SaaS、開発者ツール、クリエイターツール）の GTM・拡張担当。投資家も副次的な買い手。
- 商品: 日本展開の再現性のある方法。形は「主張 × 実験」の対。「日本人は〇〇で止まる、なぜなら△△」という主張に、「実際に日本語の扉を置いて、N 人来て M 人が進み、残りはここで止まった」という装置の実験結果が付く。文化論だけでは売れない。実験が付いて初めて売れる。
- 値段の比較対象はニュースレターではなく、日本進出の失敗コスト。日本法人を作って撤退する会社にとって、事前に止まる場所を知れるのは拍子抜け価格（codex 柱 03）。
- 段階: 無料の信号（装置が出す週次の「日本の反応」）→ 有料の分析 → 高額の個別（あなたのツールで実験を回す、日本展開の設計）。最初の 10 人に聞くところから。

### 2.2 装置の位置づけ

- **アフィリエイトはやらなくてよく、利益が出なくてよい。** 本命は海外ベンダー。だから採算度外視で、丁寧にサイトと動画を作れる。
- 紹介リンクや /go/ の帳簿は、収入源ではなく「日本人が本当に申し込んだか」を測る計器。ゼロでも、ゼロの理由が記録されていれば商品になる。
- Foreword（foreword.project-haru.org）は公開実験場。**まるで日本支社のような顔**で、丁寧な解説・使い方・比較を置く。SEO は徹底する。
- 風見鶏（Bluesky bot）は**表現の実験装置**。市場を調べるのではなく、日本人がどういう言い方なら見知らぬツールのページを開くか、動画を見るかを測る。腕は「ソース」から「表現」へ。
- 動画（TikTok、YouTube）は、そのツールの「伸びそうなカット」。話者はあえてずんだもん。日本人は ElevenLabs の声を聞き慣れておらず、アメリカ人には感覚的に手を出しにくいアニメの手法。ここも表現の実験。**日本語の動画は Foreword 名の新チャンネル。** MOSTLY TRUE JAPAN LAB は地図と世界の豆知識の路線（別セッション）で、この事業の一部ではない。英語で海外ベンダーに向ける動画の置き場は未定。

### 2.3 対象ツールの選び方

- 海外では広く使われているのに、日本ではほとんど紹介されていないもの。
- ChatGPT のように壁を突破済みのものは除く。
- おそらくアフィリエイトプログラムが無い。だから誰も本気で紹介していない。それが空白の狙い方。
- 日本人も絶対に入るべき、と言えるもの。日本から使える（決済、地域制限）。
- まず 20〜30 本を選ぶ。選定は `docs/research/` に記録する。

### 2.4 名前と顔

- 名前は Foreword（フォアワード）。本の序文。読者が本文（海外のツール）に入る前に読む日本語の一文。2026-09-12 夜に決定。Foreword は北欧家具店と被るため、Dejima はタカさんの感覚に合わないため、それぞれ却下（`docs/decided-not-to-do.md`）。
- 日本支社の「顔」はするが、その会社だと名乗らない。運営者は MaiWay / 川崎崇史と表記する。ツール名は紹介目的で使い、ロゴは各社のブランドガイドに従う。
- 言語切替に English を最初から置く。英語側は、海外ベンダーが最初に見る「この実験場は何か、誰がやっているか」の一枚。

### 2.5 場所

- Foreword: foreword.project-haru.org、Astro + Cloudflare Workers、`../foreword/`（フォルダ名は改名待ち、中身は Foreword）。当たったら独自ドメインへ 301。
- 風見鶏: この repo。裏方の計器。**2026-09-12 夜、統合を決定**: Bluesky のハンドルを `foreword.project-haru.org` に変える（サイトが `/.well-known/atproto-did` を返すよう配備済み）。5 ソースの投稿は停止（sources.json で全て enabled=false）。エンジンは残し、腕を「ツール × 表現の型」に作り替える。**2026-09-13 改訂**: 風見鶏の役割に「調査と拡散」を足す。Show HN と GitHub 新着を投稿源に戻し、投稿は英語のままではなく OpenAI API で日本語の一言を付ける（題名と説明文にある内容だけ。評価語は足さない）。どの海外ツールが日本語圏で開かれるかの計測が、Foreword に載せるツールの選定に返る。
- project-haru.org 本体には置かない。実験が動いたら Story を 1 本書いて渡すだけ。
- 動画の制作は `../video-lab/` の型（Remotion、VOICEVOX）を使う。

## 3. チャネルの役割

| チャネル | 役割 | 測るもの |
|---|---|---|
| 風見鶏（Bluesky） | 表現の実験。同じツールを複数の言い方で出し、どれが開かれるかを測る | 投稿ごとの湊への渡り率。表現の型ごとの差 |
| Foreword（サイト） | 日本支社の顔。丁寧な解説・使い方（実スクショ）・比較・日本からの申込み方。検索で残る | 検索流入、滞在、次のページ、扉のクリック、申込（任意） |
| TikTok | 伸びそうなカットの短尺、ずんだもん。波を見る | 再生、湊へのクリック |
| YouTube | 検索向けの手順動画。題名は Google の検索結果を見据える | 検索流入、説明欄クリック |

```
 候補ツール（20〜30本）
      │
      ├─▶ 風見鶏: 表現A / B / C で投稿 ──▶ どれが開かれたか
      │
      ├─▶ Foreword: 解説・使い方・比較・申込み方 ──▶ どこで止まったか
      │
      └─▶ 動画: 伸びそうなカット（ずんだもん） ──▶ 見られたか、来たか
                       │
              /go/ と帳簿（実験ノート）
                       │
        主張 × 実験 の対 ──▶ 海外ベンダーへ（無料の信号 → 有料 → 個別）
```

## 4. 作る順番

0. 候補ツール 20〜30 本を選ぶ（調査中）。
1. 「なぜ買わないか」の主張 5 本を下書きし、各主張に装置で回せる実験を対にする。タカさんが直す。
2. Foreword の型を 1 ツール分、丁寧に作る。解説、使い方（実スクショ）、比較、日本からの申込み方、止まりどころ。核を先に目視。
3. 風見鶏に「表現」の腕を足す。同じツールを複数の言い方で出し、渡り率を測る。変更はこれ一つ。
4. 動画の型を 1 本。ずんだもん、伸びそうなカット。TikTok と YouTube。
5. 英語の一枚。タカさんが誰で、この実験場が何か。
6. 10 人に聞く。登録するプログラムのパートナー担当や、対象ツールの GTM 担当に、装置の出した「日本の反応」を一枚見せて、毎週欲しいか、いくらなら払うか。

## 5. 何を拾い、何を拾わないか

### 拾う

- 海外で広く使われ、日本で紹介されていないツール。日本人も入るべきと言えるもの
- 実際に触って、実スクショで説明できるもの
- 日本語圏で実験できる表現・見せ方の型

### 拾わない

- 壁を突破済みのツール（紹介しても空白が無い）
- 医療・金融商品・法律・政治・災害の指示に関わるもの
- 成人向け、詐欺めいたもの
- 文化論だけで実験が対にならない主張

## 6. 何を測るか

| 段 | 指標 | 取り方 |
|---|---|---|
| 表現 | 投稿の型ごとの湊への渡り率 | 風見鶏の記録と /go/ の帳簿（SubID = bsky.投稿ID） |
| 理解 | ページの滞在、次のページ、比較ページへの遷移 | Cloudflare Web Analytics |
| 止まりどころ | 申込み手順のどこで離脱するか、日本のカードが通るか、日本語が無い画面はどこか | 実際にやって記録（実験ノート） |
| 申込 | 扉のクリックと成果（任意） | /go/ の帳簿、プログラムの管理画面 |
| 商品 | 主張 × 実験の対の数、聞いた人数、払うと言った人数 | HANDOFF に記録 |

- いいねを目的にしない。渡り率と止まりどころが本体。
- 一度に変える改善は一つ。効果は次の実測で判断し、予測で断定しない。

## 7. 自動化の順番

1. 風見鶏の投稿と計測: 済み。日本語の一言（OpenAI API、投稿直前の 1 呼び出し）: 2026-09-13 実装、Secrets 登録待ち。表現の腕を足すのは次。
2. 実スクショ: ブラウザ自動操作で撮る手順を作る。手で撮るのは最初の 1 ツールまで。
3. 記事の生成: 型が固まったら Claude API で下書き、タカさんの目視、慣れたら自動。
4. 動画: Remotion + VOICEVOX（ずんだもん）を Actions で。YouTube Data API の OAuth はタカさんが一度だけ。TikTok は手動のまま。
5. 週次レポート: 表現 × ツール × チャネルの渡り率と止まりどころを一枚に。これがそのまま海外ベンダーへの「無料の信号」の元になる。

## 8. ガードレール

- 運営者を明記する。日本支社の顔はするが、その会社だと名乗らない。ロゴと商標は各社のガイドに従う。
- 紹介リンクを置くページには PR 表記（置かなくてもよい）。
- 投稿文に**事実**を足さない（元データに無い機能・数字・実績・評価語）。**視点**は足してよい（誰に向くか、どんな場面で試す価値があるか、という誘いの一文）。風見鶏の名の通り風向きは変えないが、Foreword は風を強くしないと意味が無い（タカさん、2026-09-13）。サイトと動画は実スクショと実際にやった事実だけを書く。
- 過去のログを書き換えない。秘密情報はコードにも会話にも書かない。
- アカウント作成、契約、決済、OAuth は人がやる。
- 海外ベンダーに出す数字は、帳簿から出せるものだけ。

## 9. 役割

- タカさん: 顔と主張。海外に対する信用そのもの。主張 5 本の中身、10 人に聞く、週 1 回のレポートの判断。
- ハル: 装置の設計・実装・計測・レポート、サイトと動画の制作。調べ物は Sonnet / Opus に振る。方針を変えたらこの文書と HANDOFF.md を更新する。

## 10. 保留していること

- アフィリエイト収入: 目的から外した。計器として残す。
- 中小企業向けに「業界版の装置」を月額で売る式: 候補として残す。海外ベンダー向けが先。
- 独自ドメイン: 当たってから。
- 海外向けの日本語→英語の 2 台目サイト: 英語の一枚から始める。
